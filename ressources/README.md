## Prompt Templates Quick Reference

### The RICE Framework
```
ROLE: [Who should Claude be?]
INSTRUCTIONS: [What should Claude do?]
CONTEXT: [What background info is needed?]
EXAMPLES: [What does good output look like?]
```

### XML-Structured Prompt
```xml
<role>[Your role description]</role>
<task>[The specific task]</task>
<constraints>[Rules and limitations]</constraints>
<output_format>[How you want the result]</output_format>
<examples>[Good and bad examples]</examples>
```

### Mega-Prompt Structure
```
# IDENTITY
# MISSION
# CONTEXT
# DETAILED INSTRUCTIONS
# CONSTRAINTS
# OUTPUT FORMAT
# QUALITY CRITERIA
# EXAMPLES
```

## Glossary

| Term | Definition |
|------|-----------|
| **AI / Artificial Intelligence** | Computer systems that can perform tasks typically requiring human intelligence |
| **API** | Application Programming Interface — how software components communicate |
| **Artifact** | A standalone piece of content generated by Claude (code, document, app) |
| **Claude Code** | Command-line tool for building software with Claude |
| **Context Window** | The amount of text Claude can process at once (~200K tokens) |
| **Custom Instructions** | Persistent rules that shape Claude's behavior in a Project |
| **Knowledge Base** | Files uploaded to a Project that Claude can reference |
| **LLM** | Large Language Model — the type of AI that powers Claude |
| **MCP** | Model Context Protocol — standard for connecting AI to external tools |
| **Mega-Prompt** | A comprehensive, detailed prompt designed to produce complete output |
| **n8n** | Open-source visual workflow automation tool |
| **Node** | A single step/action in an n8n workflow |
| **Project** | An organized workspace in Claude with persistent settings |
| **Prompt** | The text input you give to Claude to get a response |
| **Prompt Engineering** | The skill of crafting effective prompts for AI |
| **Token** | A unit of text (~4 characters or ~¾ of a word in English) |
| **Webhook** | A URL that receives data when an event occurs |
| **Workflow** | A sequence of automated steps connected together |
